# TASKS — GrowthOS backlog (mirror of Jira project KAN)

This contains the active **KAN** (GrowthOS) backlog. Completed rows are preserved in
[TASKS-COMPLETED.md](TASKS-COMPLETED.md). Keep active work and Jira in sync as work progresses.

**Sprint management:** [workflow and commands](docs/sprints.md), with lifecycle state in
[SPRINTS.json](SPRINTS.json). Run `pnpm sprints complete-ready` at the end of each work run;
completed active sprints automatically archive their done rows. Unfinished tasks require
explicit carry-over when closing a timeboxed sprint.

**Status legend:** `todo` · `in-progress` · `done` · `needs-human` (a human must act — accounts,
billing, secrets, external approvals) · `blocked-by` (waiting on another story; see Notes).

**How a scheduled run uses this file:** read [PROGRESS.md](./PROGRESS.md) + this file, pick the next
`todo` in sprint order (lowest sprint first), skipping `needs-human` and `blocked-by` items whose
blocker is unfinished. See [CLAUDE.md](./CLAUDE.md) for the full working rules.
